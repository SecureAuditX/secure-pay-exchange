## Overview

FinCryptiX is a modern fintech web application for secure payments, currency exchange, crypto management, and live support. Built with HTML, CSS, Bootstrap, and JavaScript, it provides a seamless user experience for banking, crypto, and financial operations.

## Features

- **Dashboard**: Overview of balances, earnings, transactions, and quick transfer.
- **Payments**: Secure card payment modal with billing address.
- **Exchange**: Currency and crypto exchange calculator.
- **Live Chat**: Modal-based support chat for instant help.
- **Settings**: User profile, notification preferences, theme selection, and currency choice.
- **Sign Up/Login**: User registration with validation.
- **Responsive Design**: Works across devices, powered by Bootstrap.
- **Charts**: Earnings and money flow visualized with Chart.js.

## Project Structure

- `Dashboard.html` — Main dashboard with widgets and charts.
- `Exchange.html` — Currency and crypto exchange section.
- `Payments.html` — Payment settings modal.
- `Settings.html` — User settings modal.
- `Livechat.html` — Live chat support modal.
- `Fincryptix.html` — Landing page with services, partners, and terms.
- `FinLogin.html` — User sign-up/login form.
- `DashStyle.css`, `FinStyle.css`, `LoginStyle.css` — Custom stylesheets.
- `README.md` — Project documentation.

## Getting Started

1. **Clone the repository**  
   ```sh
   git clone https://github.com/yourusername/fincryptix-bank.git
   cd fincryptix-bank
   ```

2. **Open in Browser**  
   Open `Fincryptix.html` or `Dashboard.html` in your browser.

3. **Dependencies**  
   - [Bootstrap 5.3](https://getbootstrap.com/)
   - [Chart.js](https://www.chartjs.org/)
   - [jQuery](https://jquery.com/)

## Usage

- Register via `FinLogin.html`
- Access dashboard and widgets via `Dashboard.html`
- Exchange currencies in `Exchange.html`
- Manage payments in `Payments.html`
- Update settings in `Settings.html`
- Get support in `Livechat.html`

## Customization

- Update styles in `DashStyle.css`, `FinStyle.css`, `LoginStyle.css`
- Add new currencies or partners in HTML files
- Extend chart data in dashboard scripts
